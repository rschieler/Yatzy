# Yatzy

Würfelspiel fürs Handy: gegen den Bot, solo oder zu mehreren (2–4) auf einem Gerät.

Live: https://rschieler.github.io/Yatzy/ (GitHub Pages, Branch `main`, Root)

- Alles in `index.html` (HTML, CSS, JS, keine Build-Schritte)
- Installierbar (`manifest.webmanifest`, `sw.js`), offline spielbar
- Spielstand, Bestenliste, Bilanz gegen den Bot und Einstellungen nur lokal im Browser (localStorage `yatzy2.*`)
